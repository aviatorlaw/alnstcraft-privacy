# ALNSTCRAFT - Privacy Policy
To comply with Discord's Developer Terms of Service, we are required to explain how we use your Discord data in relation to DiscordSRV, and how you can request deletion of it.
## Data We Collect
* We collect your User ID when you link your Minecraft account to your Discord account.
  * We use this to confirm that you are allowed to join the server.
  * We use this in case of any punishment taken on the Minecraft server that requires us to know your Discord account.
  * We use this so that you are automatically banned from the Minecraft if you are banned on the Discord server.
  * This is stored indefinitely at rest.
* We collect any messages that you send in unknown, which is stored in the Minecraft server logs.
  * We use this to relay your messages in the aforementioned channel into the Minecraft server.
  * We use this in cases where evidence is required in a moderation case.
  * We store your messages for a month before deletion.
## Request Deletion
If you wish for your data to be deleted, you can open a ticket in [#support](https://discord.com/channels/1491267604617232504/1555803814454632479) (or in [#server-support](https://discord.com/channels/1491267604617232504/1492701747347460098) if you lose access) to request the deletion of your data. Under GDPR, we can refuse the deletion of your data in [certain circumstances](https://dataprotection.ie/en/individuals/know-your-rights/right-erasure-articles-17-19-gdpr#:~:text=Are%20there%20circumstances%20in%20which%20the%20right%20to%20be%20forgotten%20will%20not%20apply%3F).
